# myz_game

纯前端小游戏合集，直接双击对应 HTML 文件即可游玩，无需安装依赖。

- [马泽一的世界](mazyi-world.html) —— 方块沙盒世界：无限地形、昼夜循环、挖掘建造、飞行、聊天生成飞机、自动存档。
- [马泽一的飞机大战](plane-war.html) —— 竖版飞机射击游戏。

## 马泽一的世界

打开 `mazyi-world.html` 开始游戏。这是一个类似《我的世界》的创造模式方块世界：

- 随机种子生成无限地形：平原、丘陵、山脉、雪峰、湖泊、沙漠、森林与地下洞穴
- 地下世界：8 种矿脉（煤/铁/铜/金/青金石/红石/钻石/绿宝石矿石，深层 15 层以下替换为深板岩）、大溶洞（洞顶萤石、洞底岩浆块照明）、随机矿道（木板地板 + 原木支架 + 火把）
- 完整昼夜循环：太阳、月亮、星空、黄昏霞光，夜晚环境光会变暗
- 夜晚僵尸会在没有光亮的黑暗处生成：向玩家移动、近身攻击（扣心、击退、红屏）；左键攻击僵尸（剑伤害更高），击杀掉落腐肉（小概率铁锭）；白天僵尸会燃烧死亡；创造（飞行）模式下僵尸不会生成也不会攻击
- 玩家 20 点生命（10 颗心），死亡后在出生点重生；生命与书包内容自动存档
- 方块硬度对齐真实 Minecraft：按住左键按进度挖掘（准星下方显示进度条），工具类别匹配才加速（镐挖石头、斧砍木头、锹挖土沙、锄收割），石头掉圆石、玻璃树叶不掉落、矿石掉对应矿物
- 镐的挖掘等级：木镐=石头；石镐=+木头、铁矿；铁镐=+金矿；金镐=+钻石矿；钻石镐=+远古残骸（下界合金矿）、黑曜石；下界合金镐=所有方块
- 第一人称手持方块、挥动动画、行走视角晃动；挖掘/放置/脚步按材质发出不同音效
- 鼠标左键挖掘、右键放置，快捷栏支持 `1`–`9` 和滚轮切换
- `WASD` 移动、空格跳跃、`Shift` 疾跑；双击空格或按 `F` 切换飞行，飞行时按 `Shift` 或 `N` 下降
- `E` 打开创造物品栏（快捷栏右侧灰色方块按钮）：
  - 分类收录建筑、自然、矿物金属（含 8 种矿石）、羊毛、实用、更多方块、交互方块、物品、工具、书包与飞机涂装，共 160+ 种方块和物品
  - 「矿物金属」收录煤/铁/铜/金/青金石/红石/钻石/绿宝石矿石，地下按矿脉自然生成
  - 「更多方块」收录深板岩、凝灰岩、方解石、下界/末地、海晶石、浮冰、红沙、菌光体、远古残骸、下界合金、铜、紫水晶等 38 种扩展方块
  - 「交互方块」收录可右键开合的橡木栅栏门、拉杆、橡木活板门与橡木楼梯，以及橡木栅栏、梯子
  - 「工具」收录木/石/铁/金/钻石/下界合金 × 剑、镐、斧、锹、锄共 30 件工具，均有合成配方
  - 飞行模式（创造模式）下点击任意物品即可免费放入当前快捷栏格
  - 内含 3×3 合成表与 77 条配方（含 8 级书包、铜块、梯子、拉杆、打火石、活板门、楼梯），点击配方查看材料，点击产物同样可免费取用
  - 物品栏、选中格和快捷栏内容都会自动存档
- 火把是可放置的发光方块，采用十字立体模型，会照亮周围的地面和墙面；萤石、红石灯同样会照明
- 挖掉方块会掉落物品，走近自动拾取并累加数量；快捷栏每格显示数量，步行模式放置会消耗，飞行（创造）模式不消耗
- `L` 丢弃 1 个当前手中物品（生成可见掉落物，走近可拾取），`M` 删除整组当前手中物品
- `T` 打开聊天框，输入机型即可在面前生成方块飞机：
  - `歼-20`、`F-22`、`苏-57` → 战斗机（带座舱、三角翼、垂尾、发动机尾焰）
  - `波音747`、`空客A380`、`运-20` → 客机 / 运输机
  - `武直-10`、`直升机` → 直升机；`B-2`、`轰-20` → 飞翼轰炸机
  - `无人机`、`双翼机`、`航天飞机` → 对应机型；输入颜色（红/蓝/黄）会改变涂装
  - 机型后加 `H`（例如 `歼-20H`）不生成实体飞机，而是在面前生成灰色半透明虚拟蓝图，玩家可照着用真实方块搭建；输入「清除蓝图」可移除
  - 机型后加空格和数字 `1`–`3` 控制大小：`1` 为当前大小，数字越大飞机越大（例如 `歼-20 2`）；蓝图同样支持，例如 `歼-20H 2`
- `ESC` 暂停，世界进度（种子、时间、位置、快捷栏、所有建造）自动保存在浏览器本地
- 暂停界面和物品栏底部都有「鼠标灵敏度」滑杆，拖动即时生效并自动记忆
- `0` 打开模组栏，点击模组即可启用/停用，状态自动保存；「背包模组」提供 8 级书包：皮革 9 → 木质 18 → 石质 36 → 铁质 72 → 金质 144 → 钻石 288 → 下界合金 576 → 无尽书包（容量无限，需 9 个下界合金书包合成），合成配方见模组栏底部说明；书包放入快捷栏后手持会显示提示，右键或按 `B` 打开，点击物品在书包与快捷栏之间双向移动，内容自动存档
- 梯子可攀爬：贴着梯子按 `W`/`空格` 上升、`S` 下降；拉杆右键开合；打火石右键点燃 TNT——点燃后有 3 秒引信（冒烟冒火星），爆炸还会连锁引爆附近的 TNT；活板门右键开合，打开的活板门上方若有方块挡住，玩家会自动压低身体爬过 1 格高的通道（走出后自动起身）；楼梯是半高台阶方块，可以直接走上 1 格高差
- 箱子：右键打开 27 格储物界面，点击在箱子与快捷栏之间双向移动物品；挖掉或被炸毁的箱子会把存的东西全部掉出来；箱子内容自动存档
- 座椅：右键坐上去（视线变矮），按空格或移动键站起；5 块橡木木板合成 2 个
- 屏幕顶部有目标显示屏：准星指着方块时显示方块名称，指着僵尸时显示它的血量条
- 丢在地上的物品 90 秒后会自动消失
- 暂停界面或标题界面可点「换个世界」重新生成一个全新世界
